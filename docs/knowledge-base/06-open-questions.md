#### Q27 · 「至少摸 1 张」撞上「一张都不摸」，听谁的？ —— ✅ 2026-07-30 已裁定：**不摸**

~~2026-07-29 裁定 S9 后，这两个效果无法同时出现在一个人身上~~
**2026-07-30 S9 更正后本题复活**：狂欢改为**双方各按自己骰子获得 buff**，且**对方保留技能**——
持恩惠的对方掷出和 4（狂欢「被惩罚不摸」）后，恩惠的「至少 1」（L5）与狂欢的「不摸 = 0」（L4）
就真的同框了。原推导（只有灾难方获 buff 且技能移除）不再成立。

**场景**：小满持恩惠，被灾难触发拉去掷 2 骰、和为 4，获得「被惩罚不摸」。下回合阿柴对她打出 +2。

**✅ 2026-07-30 裁定（复活当日即裁）**：**摸 0**。狂欢和 4 的「被惩罚不摸」= **跳过该次惩罚摸牌**——
是程序级的跳过，不是把数值覆盖成 0：摸牌事件根本不发生，恩惠的「至少 1」（L5）无从生效。
02 §7 已把狂欢和 4 从 L4 示例中移出、标为事件跳过。实现狂欢时按跳过建模，不进层级 reducer。

**引擎现状**：狂欢尚未实现，无需改动；届时按「跳过事件」建模（不走层级 reducer），本题即闭环。

#### Q47 · 神化是标记还是状态 —— ✅ 2026-07-29 已裁定：**标记**

03 §4 把神化列为**状态**并规定「所有状态不能叠加多层」，§5 的标记表里**也有神化**且写着「主神在场时全局 ≤3」——显然可计数。两节自相矛盾。

**⚠️ 但由此产生一个新矛盾，需要你再裁一次**：

- **G1（新表述）**：N 枚神化 → 连出 **N+1 张牌**

**场景**：小满有 **1 枚神化**，并且持有**并列**（两张同色同数可一起打出）。她手上有红3、红3、蓝5、蓝5。

**她这回合最多能打几张？**
- **A → 2 张**。G1 说「N+1 张」，那就是 2 张牌封顶，并列在这里没有额外收益。
- **B → 4 张**。G1 的「N+1」数的是**轮**，每轮可以用并列打 2 张 → 2 轮 × 2 张 = 4 张。这是 G2 的原意。

**遗留（与本裁定无关，仍待裁）**：被取消者若持**司夜**，他打出的洗牌是无色牌，本该触发司夜①
「打出无色牌掷骰获盗」——**引擎当前在取消路径上不跑这一步**。理由是实现层面的：获盗要开掷骰
接管窗口，而那个窗口的续跑写死了「从掷骰者交回合」，与取消的「从取消者的下家继续」直接冲突。
取消者自己那张洗牌同样不获盗，两边一致。极罕见，不阻塞。

#### Q60 · 反应窗口里一个人「放弃」，是不是替全场放弃？ —— ✅ 2026-08-01 已裁定：**A，先响应者定结果**

**来源**：2026-08-01 实现洗牌③（05 §2b 裁定 洗-3）时发现。裁定写了「窗口开给**所有**手上有洗牌牌的其他玩家、**先到先得**」，但没写**放弃**的粒度。

**场景**：小满打出洗牌并选①（合并重分）。阿泰和阿雅手上各有一张洗牌牌，两人都被开了取消窗口。**阿泰点了「放弃」。**

**阿雅还能取消吗？**
- **A（引擎当前行为）→ 不能**。任何一名 actor 放弃即关窗口，①当场执行。「先到先得」被读作「先响应者决定结果」，放弃也是一种响应。
- **B → 能**。「先到先得」只修饰**取消**这个动作；放弃只把自己从 actors 里摘掉，要等 actors 全空（或超时）①才执行。

**为什么要问**：牌组里有 3 张洗牌，两名对手同时持有完全现实。按 A，先手放弃者可以替队友弃权——多人局里这是个可被利用的操作。按 B，窗口要多轮流转，节奏变慢。

**范围提醒**：这**不是**洗牌独有的。劫营♦10 的 `interrupt` 窗口（01-G5）是同一个形状、同一段代码结构，两名玩家同时持劫营时行为一样。**裁定请一并覆盖劫营**，否则两个「同构」的窗口会不同构。

**✅ 2026-08-01 裁定**：**A**。规则制定人原话「谁先取消按先者算」——窗口是**先响应者定结果**的：
多人抢着取消时以最先那一个为准；一名 actor 放弃即关窗口、①照常执行。劫营♦10 的 `interrupt`
窗口口径相同，两个「同构」窗口保持同构。

**引擎现状**：两处本来就按 A（`raid.ts::settleRaid` 与 `shuffle-card.ts::settleShuffleCancel`），
**无需改动**。

#### Q61 · 司夜③ 的末牌放宽，够不够得到「洗牌①重分后分到 0 张」？ —— ✅ 2026-08-01 已裁定：**够，且更早**

## P0（第四批）— 吟游歌声全表补齐时浮现（2026-08-02）

歌声全表由规则制定人给出（见 04 ♣5），四支歌声的**层级落点**没有歧义；
下面三条是补表时才露出来的边界，都会改变引擎的实现形状，所以拎出来单问。

#### Q62 · 歌声的作用域 —— ✅ 2026-08-02 已裁定：**全场**

原话：「Q62 是全场技能，×2 是惩罚最后计算的，即先计算加减」。

- 歌声**对全场所有人生效**，不只作用于吟游持有者。所以活泼板 +1 让对手也多摸、
  战争序 ×2 让自己被罚时也翻倍——歌声是双刃剑，这正是「每回合可切换」的意义
- 「×2 是最后计算的，先计算加减」= **L2 加减 → L3 倍率**，与 02 §7 现有层序**逐字一致**，
  不必改层。例：链上 4 张 → 活泼板 +1 → 5 → 战争序 ×2 → **10**（不是 4×2+1=9）

**引擎影响**：`DrawModifier` 只有 L4 带 `scope: "self" | "global"`，**L2/L3 要补作用域**，
并且 `drawModifiersFor` 的采集口径要从「按摸牌者收自己的修正」扩成「自己的 + 全场的」。

#### Q63 · 樱时雨的口径 —— ✅ 2026-08-02 已裁定：**只管惩罚，两处一致**

原话：「古神的那个效果和樱时雨是一模一样的，都是只是惩罚变为 1，其他的摸牌数不变」
（原话说的「古神」指的是 **05 §时神 Fade ≥5** 那条永久樱时雨——古神 Ricin 没有这个效果，
下文与各处引用一律按**时神**记）。

05 §时神 ≥5 的「摸牌恒为 1」是**漏了「惩罚」两个字**，已改。两处都是
**惩罚摸牌数恒定为 1**，规则摸牌与技能摸牌照旧。引擎侧那条 L4 修正带 `applies_to: [punish]`。

**并且补一条**（同日原话）：「**本身是 0 的惩罚也变为 1**」。所以 L4 的覆盖对 **0 基数同样生效**——
强袭掷 0 让惩罚基数变 0 时，樱时雨仍把它抬回 1。这与 02 §7 里 L5 那条
「下限不得高于 L0 基数」**不冲突**：L5 是减免的地板（不能无中生有），L4 是覆盖（本来就是改写）。

#### Q64 · 行进曲的确切语义 —— ✅ 2026-08-02 已裁定：**A（能打、有效，只是不改色）**

原话：「第 1 个就是正确的，能打并有效但是不能改变现在的颜色」。

- 变色 / +4 **照常打得出、效果照常结算**（+4 的惩罚成立并传给下家）
- 唯一的差别：**跟色维持原样**，打之前是红、打完还是红。提交时不带 `chosenColor`
- 落点是 `color_rule`，不进 02 §7 的摸牌层级表

#### Q65 · 歌声在封印 / 换走时怎么处理 —— ✅ 2026-08-02 已裁定：**只压制，不清空**

原话：「被封印和换走后，即失去目前的歌声效果，然后重新获得后（一般是解除封印），
变为被封印前歌声状态，不是无歌声」。

- 封印期间歌声**效果失效**（01-P9 的「封印含被动」照旧），但**当前是哪一支歌声要留着**
- 解封 / 重新持有 → **恢复到被封印前那一支**，不是回到「无歌声」
- 「亮出时为无歌声」只管**第一次亮出**，不是每次恢复都重置

**引擎影响**：歌声存在牌桌上，压制层只挡它的**读取**，不改它的值——与 `marks` 被封印时的
处理同构，不需要新机制。

#### Q66 · 同桌两个吟游 —— ✅ 2026-08-02 已裁定：**技能全场唯一；真撞上则最后唱的算**

原话：「不能有两个吟游，即请确保技能唯一……如果真的有两个吟游了，按照每次最后修改歌声的
那个玩家计算」。

- **技能全场唯一**是硬要求（见 01-S2b）。引擎现状：`openDraft` 从**同一副洗好的池**里
  不重复地轮流发，四人的候选集两两不相交——**唯一性已经天然成立**，不必改实现，补回归测试即可
- 兜底口径：歌声是**全场单个槽，后唱覆盖先唱**。A 唱行进曲 → B 唱战争序 → 现在是战争序；
  A 再唱行进曲 → 战争序消失 → 现在是行进曲。所以引擎里歌声**不是逐座位的字段**，
  是牌桌上的一个值 + 「谁唱的」
- **时神的永久樱时雨是例外**：它不占那个全局槽，永久跟着时神本人（`scope: self`），
  与场上的歌声并存。L4 > L3，所以战争序在场时时神自己仍是 1

#### Q67 · 专精♥9「该色 +2 无效」的确切语义 —— ✅ 2026-08-02 已裁定：**打得出，但你不摸**

原话：「那张 +2 可以被打出，但是由于颜色一致不用摸牌，仍然是惩罚回合，但不摸牌，
其他结算正常，例如可以叠或者吃下（吃下不摸牌）」。

牌桌例（原话）：A 打绿色 +2，B 是绿色专精——

- B 手里**没有**惩罚牌（叠不了）→ B **不摸牌**，回合交给 C。行为上等于跳过了 B
- B 手里**有** +2 → 照常叠，到 C 就是 A+2 + B+2 = **4 张**

所以它**不是** `play_legality`（那张牌照打不误），而是**受罚侧的免摸**：

- 惩罚回合的性质不变（P1 的「惩罚回合不能用主动技能」照旧）
- 叠 / 吃下两条路都在，只是**吃下时摸 0 张**
- 传给下家的贡献一张不少（B 的免摸不减 A 那一段）

**+4 不适用**：+4 是无色牌，没有「该色」可谈（同 04 ♦10 劫营「同色同数只有数字牌成立」的口径）。

**引擎落点**：与狂欢和4「被惩罚不摸」同款——02 §7 明写那一条**不在 L4**，
它是**跳过整个摸牌事件**（06-Q27），事件不发生，任何数值修正（含 L5 下限）都无从生效。
专精走同一条路，不新造机制。

混色链按 Q68 **逐段**免。

#### Q68 · 混色叠链下，专精免掉的是「整个事件」还是「你那一色的那一段」？ —— ✅ 2026-08-02 已裁定：**B，只免自己那一色的段**

Q67 的例子是**单色链**（只有 A 那一张绿 +2），没有歧义。但叠链可以混色：

> A 打**绿** +2 → B 叠**红** +2 → 轮到 C，C 是**绿**专精，选择吃下。

C 该摸几张？

- **A｜整个事件跳过**：摸 **0**。与狂欢和4 同构，实现最简（一个布尔判定）。
  代价：一张绿 +2 就免掉了整条链，红那一段的贡献也白打了
- **B｜只免自己那一色的段**：摸 **2**（红那一段照吃）。更符合「**该色** +2 无效」的字面。
  代价：**破 01-P11**「先加总各段贡献，再套用」——受罚侧要按段拆开算，
  而整个 L0–L6 的机器都建在「加总后的一个数」上。这是这一批里唯一会动那台机器的改动
- **C｜只看链顶**（C 要接的那张，即 B 的红 +2）：**不免**，摸 4。
  「该色」指的是砸到你脸上的那一张

**裁定原话**（2026-08-02）：

> A 打绿色 +2，B 接红色 +2，C 持有绿色专精没有可以叠的牌，那么 C 只加红色的 +2，
> 绿色的 +2 被免掉了；如果 C 也有 +2，那么到 D 的话 D 没有专精，所以就是 +2+2+2 = **+6**。

两条推论，都要钉住：

1. **免摸只对吃下的那个人生效**，链上贡献一张不减——C 免掉的是「C 摸的时候不数绿那段」，
   不是把 A 那张从链上拿走。C 接着叠自己的 +2，传到 D 就是 2+2+2=6，D 无专精照吃满
2. 因此 `chain.total` 始终是全额，**免摸发生在受罚侧读它的那一刻**（每个受罚者各算各的）

顺带两条同源的小边界，一并写死：

1. **强袭倍率**：A 用强袭把绿 +2 掷成 ×2（那一段贡献 4 张），C 绿专精吃下 → 免掉的是
   **那一段的贡献 4**，不是牌面的 2。按段算，段里已含倍率
2. **谁打的无关**：C 自己打出绿 +2 开链时，专精不保护下家，也不保护自己（他不受罚）

**对 01-P11 的影响**：P11「先加总各段贡献，再作为 L0 基础值」仍然成立，只是**加总的口径
按受罚者过滤**：`base = Σ 不被该受罚者专精免掉的段`。L0–L6 的机器一行不改，改的是喂给
L0 的那个数怎么算出来。

**全免的边界**：过滤后 base 归 0（链上全是你的专精色）→ 走 Q67 的路子，
**整个摸牌事件跳过**（同狂欢和4 / 06-Q27），不是「摸 0 张」——否则 L5 下限会把它抬回来。
惩罚回合的性质仍在（P1 照旧）。
