# 技能属性方法论

用于把 Excel 自然语言技能**结构化**，供规则引擎、测试用例与玩家教程共用。

---

## 1. 核心字段（每条技能 / 每条子效果）

| 字段 | 说明 | 取值示例 |
|---|---|---|
| `id` | 稳定 ID | `heart-3` / `star-grandeur` |
| `name` | 中文名 | 精英 |
| `suit_rank` | 花色与点数 | ♥3 / ★ / 神 |
| `reveal_window` | 亮出窗口 | `own_turn` / `any_time` / `when_skipped` / `when_challenged_uno` |
| `effects[]` | 子效果列表 | 见下 |
| `force_reveal_ok` | 可否被强制亮出 | 默认 true |
| `force_activate_ok` | 可否被强制发动 | 默认 true；异议/夜魇等 false |
| `sealable` | 可否被血棘封印 | 默认 true |
| `upgrade_to` | 升级目标 | 宏伟→宝藏→古神 |
| `notes` | 裁定备注 | 指向 01 / Q&A |

### 子效果 `effects[]`

| 字段 | 说明 |
|---|---|
| `key` | `1` / `2` / `passive` / `on_reveal` |
| `kind` | 见 §2 效果类型 |
| `window` | 见 §3 时机窗口 |
| `cost` | 弃牌/标记/一次性等 |
| `targeting` | `self` / `single` / `all_others` / `global` |
| `once` | 一次性 / 每名玩家限一次 / 玩家人数次 / 无限 |
| `stacks_with_turn_limit` | 是否占用「每回合一条主动」——主动 true，被动 false |
| `priority` | 如血棘「优先其他技能」 |
| `modifies` | 改摸数、改惩罚、改颜色规则等标签 |
| `duration` | 效果/所赋状态的生命周期：`instant`（当场结算）/ `until_event`（直到打出 +4 等，写明事件）/ `while_revealed`（技能亮出期间）/ `until_skill_replaced`（常驻至技能被替换，如宝藏分支）/ `permanent` |
| `layer` | 若 `modifies` 含摸牌数：声明所属结算层（见 §7），如恩惠 `L2`、战争序 `L3`、伤逝 `L1` |

## 2. 效果类型（kind）

| kind | 含义 | 次数 | 典型 |
|---|---|---|---|
| `passive` | 条件满足即触发，不占回合主动次数 | 不占 | 精英、恩惠、神授 |
| `active` | 阶段 1 声明发动 | 占 1 条/回合 | 恒心、天堂 |
| `on_reveal` | 亮出当下结算 | 亮出时 | 合纵/连横「亮出时」、专精定色 |
| `on_play` | 自己打出某类牌后在阶段 3 结算 | 不占主动（除非另要声明） | 司夜获盗、强袭改倍率 |
| `response` | 响应他人行为（可非己方回合） | 按技能 | 劫营、远星、回溯 |
| `replacement` | 替换摸牌/拼点/判定 | 按技能 | 黑白换判定、染手弃牌堆 |
| `status_grant` | 赋予状态/标记 | — | 五彩、神化、同命 |
| `meta_rule` | 修改全局或自身规则 | — | 吟游歌声、专精颜色 |

**压制（Suppression）**：某窗口禁止主动技能。默认压制源：

- 惩罚回合（阶段 1 关闭）  
- 血棘封印  
- 技能免疫（对你无效，你也不触发他人技能）  
- 预兆「技能暂时失效」等  

例外写在技能上（影歌②、Excel 白名单亮出等）。

## 3. 时机窗口（window）

与 [01-decided-rules.md](./01-decided-rules.md) 回合阶段对齐：

| window | 阶段 | 说明 |
|---|---|---|
| `turn_start` | 1 | 默认主动窗口 |
| `play_phase` | 2 | 出牌/摸牌选择 |
| `after_play` | 3 | 牌面结算、on_play |
| `turn_end` | 4 | 少见 |
| `on_punish_resolve` | 惩罚摸牌后 | Q&A 延后结算 |
| `on_stack_contribute` | 惩罚牌进链时 | 强袭等只改自己那张 |
| `interrupt` | 他人出牌时 | 劫营、远星 |
| `any` | — | 极运/寄生亮出例外等 |

## 4. 目标与「单体技能」

Q&A：只能指定一名玩家的技能为**单体技能**。

引擎标签：

- `single` → 单体（可被「不能以你为目标」类效果挡住，如狂欢和为 4）  
- `all_others` / `global` → 非单体

## 5. 升级链（★ / 神）

```text
宏伟★ ──(条件)──► 宝藏★ ──(毒判定)──► ※古神
灾难★ ──(条件)──► 双方获狂欢 buff；灾难技能移除；掷4骰方且和≥5 → ❂时神技能
预兆♣9 ──(两次匹配预兆)──► ✣邪神
飞升♣K ──(出完手牌)──► ⌘主神（并指定神官）
```

开局可抽：宏伟、灾难。宝藏为技能升级形态；**狂欢是 buff 不是技能牌**。

## 7. 摸牌数结算层级（决策层级）✅

同一次摸牌可被多个来源修改（恩惠 −2、狂欢 +1、吟游歌声、忍戒、伤逝…）。**任何摸牌事件按以下固定层级结算一次**，不做技能间 ad-hoc 排序；引擎实现为按层排序的 reducer，每个修正效果声明自己的 `layer`。

```text
L0 定型   事件类型（惩罚 / 技能 / 规则摸牌）+ 基础值
          · 惩罚：链上各段贡献先加总（01-P11）；强袭×点数、精英+1 等
            「只作用于自己那张」的修正在进链时已入贡献（01-P6），不在此重复
L1 替换   整体改写计算的效果（伤逝：按张数掷骰，明文「不受其他技能影响」）
          → 命中 L1 直接得最终值，跳到 L5
L2 加减   恩惠 −2 / 狂欢和2「所有摸牌+1」/ 狂欢和3「惩罚+1」/
          吟游·活泼板 +1 / 八门 +1 / 寄生 +1 / 弃「异」每张 −1 …（同层全部累加）
L3 倍率   吟游·战争序 ×2 …
L4 覆盖   恒定值/归零（吟游·樱时雨 恒为 1；狂欢和4 被惩罚不摸=0）
          → 冲突时：作用于受罚者自身的覆盖 > 全局覆盖
L5 钳制   效果自带下限（恩惠「至少 1」）→ 全局最终值 ≥ 0
L6 后置程序（不改数字，只改执行方式）
          忍戒：按最终值 N 多摸 min(N,6) 张再弃等量
          染手：改摸牌来源（弃牌堆）　领域：改去向（扣置）　近卫：逐张交牌
```

裁定随附：

- **忍戒 vs 伤逝**（04 原疑点）：二者都是持有者自身技能，S2 一人一技能，**不可能同时在一名受罚者身上**；跨玩家各自独立结算，无冲突。忍戒属 L6 后置程序、伤逝属 L1 替换，层级已兜底 → 疑点关闭。
- 每次摸牌事件**独立**走一遍层级；同命复制的是 L5 后的最终数字，复制方再按自身效果走自己的层级（其技能若含摸牌修正照常适用）。

## 8. 区域与可见性模型 ✅

glossary 定义了 明/扣置/展示/明示/亮出手牌 五种可见性，引擎状态必须显式建模（`projectView` 据此裁剪）：

**区域（zones）**

| zone | 说明 |
|---|---|
| `deck` | 摸牌堆（全隐藏） |
| `playPile` | 出牌堆（全公开） |
| `discardPile` | 弃牌堆（全公开；染手可改抽取来源） |
| `hand[player]` | 手牌，每张带 `revealed` 标志（明示=true，正面向上但仍是手牌；洗牌后重置，01/glossary） |
| `tableau[player]` | 个人明/扣置区（移除游戏、保留面前）：`faceUp`（明置，公开）/ `faceDown`（扣置，仅所有者与引擎可见） |

**瞬时可见事件**：`展示` 不改区域，作为事件记录（`revealedTo: [seats]`，一次性）；`亮出手牌` = 全手牌置 `revealed`。

`projectView(state, seat)` 规则：`deck` 只给张数；他人 `hand` 只给张数 + `revealed=true` 的牌面；他人 `faceDown` tableau 只给张数；事件投影同理（他人摸牌事件不含牌面）。

## 9. 玩家教学用简化模型（建议）

对玩家不展示全部字段，只教四句话：

1. **回合开始用技能，然后出牌。**  
2. **被 +2/+4 时先叠或不叠；叠的时候只算你自己那张的加成。**  
3. **一人一个技能；亮出来才会生效。**  
4. **神化 = 多几轮出牌；并列 = 一轮里多张。**

进阶规则（拼点、成神、预兆）用独立「进阶手册」折叠，避免首局认知过载。
