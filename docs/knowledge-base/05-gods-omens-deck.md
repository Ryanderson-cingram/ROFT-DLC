# 诸神 · 预兆 · 牌组

## 1. 诸神

替换原技能后生效（见 01-S3）。

### ※古神 Ricin

1. 所有玩家的变色牌皆视为「毒」。  
2. 你打出「毒」时改为其他所有玩家分别打出此「毒」。  
3. 若有毒池♦5：你每次打出毒时将此毒明置在其明置区；毒池胜利时你同时胜利。

### ✣邪神 Omorph

1. 回合开始可掷骰一次，获点数枚「颠」（可当作异/盗/魂/形）。  
2. 获得任意标记时额外 +1（陨除外）。  
3. 若有强袭♦1：可控制其是否帮你改掷骰；强袭改为可重掷两次并任选结果；强袭胜利时你同时胜利。

### ❂时神 Fade

成神时按掷骰点数解锁能力（阈值累进：掷出高点自然同时满足低档；2026-07-30 补齐，原 Q42）；失去神技能时获得灾难★。

1. **≥5**：你获得**永久樱时雨**效果（**惩罚**摸牌数恒定为 1，02 §7 L4；规则摸牌与技能摸牌不受影响），且**不需要喊「UNO」**。⚠️ 2026-08-02 更正：原文写的是「摸牌恒为 1」，漏了「惩罚」两个字——与 04 ♣5 的樱时雨**一模一样**（06-Q63）。**基数为 0 的惩罚也抬回 1**（强袭掷 0 的场合）。这一份是**永久且只作用于古神本人**（`scope: self`），不占场上那个全局歌声槽，两者可以并存。
2. **≥6**：其他玩家**摸 N 弃 N（N ≤ 5）**时，你可以同时摸 N 弃 N。
3. **≥7**：你免疫「五彩」「心盲」「恋战」。
4. **=8**：其他**非神**玩家亮出手牌。

### ⌘主神 Tindra

1. 所有玩家最多 3 枚神化（**仅主神在场时**，见 01-G4）。  
2. 你回合开始：神官将一张牌放牌堆顶；你观看玩家人数张顶牌，排序并交一张给神官。  
3. 可将观看的全部交给神官；每如此做两次，神官获一枚神化。  
4. 神官指定：降临 > 无念 > 终结 > 手牌最多，取**行动顺序下家方向最近**者；神官达成胜利条件时主神同时胜利。

⚠️ Q&A 写「θ主神」，表内为「⌘主神」——文档统一用 ⌘主神，除非另裁。

### 诸神的黄昏

当场上至少两个神明时开启。

- 所有玩家回合开始可挑战神明；赢则神明获「陨」；陨达「玩家人数一半（向上取整）」则失去神技能。  
- 输则不能再挑战该神明（神明发起挑战不受此限）。  
- 拼点修正：邪神可掷骰加等级；古神非数字牌视为 +4；主神翻两张任取一张。  
- 神官不可向主神发起挑战（Q&A）。  
- **伪神视为神明**：计入两神开启黄昏；与真神可互相挑战。  
- 普通玩家只能挑战神明（含伪神）。  
- 伪神陨满：**不再算神明**（不占黄昏名额），伪神牌面效果仍保留。  
- ✅ 回合开始：挑战神明 **或** 发动主动技能，二选一。

## 2b. 毒 / 洗牌 两张功能牌的效果（2026-07-31 从 Excel 卡面补齐）

此前全库只写过这两张牌「不是什么」（P1 打出毒不是惩罚、P1b 同命不响应毒、U5 两者不能当末牌），
**效果本身从未写下**。以下逐字取自卡面。两者都是**无色牌**（打出时要定色）。

### 毒（5 张）

> **打出时摸 3 张牌并决定颜色。**

- 摸的是**打出者自己**——由 04 ♦5 毒池「你打毒**不摸**且他人各摸 3」反证：毒池改的正是这条默认行为。
- 这 3 张不是惩罚（01-P1），所以同命不响应（P1b）、恩惠也不减（它只吃 `punish` 与他人技能）。
- 定色与变色牌同一套机制（提交时带 `chosenColor`）。
- **作末牌不补摸**（规则制定人 2026-07-31）：摸完这 3 张手牌已非空，01-U5 的补摸条件不成立。毒仍是功能牌，**打完不判胜**。
- 摸的 3 张**不设 `drawnPlayable`**：01-U1 的「摸到可打即可打出」只针对「无牌可出而摸的那一张」，毒是出牌结算的一部分，摸完这一手就结束。



### 洗牌（3 张）

> **三选一并决定颜色：**
> 1. **洗牌**
> 2. **摸一弃一**
> 3. **取消一次其他玩家的洗牌**（不进入你的回合且你的下家继续出牌）
>
> （**洗牌**：合并并打乱所有玩家手牌，从下家开始每名玩家依次获得一张牌）

- **⚠️ 命名冲突**：卡面的「洗牌」= 打乱并重分**所有玩家的手牌**；与「摸牌堆见底时洗回出牌堆+弃牌堆」是两回事（后者见 01 的洗回规则）。文档提到时务必写清是哪一个。
- 选项 1 的发牌方式：合并全部手牌 → 打乱 → **从打出者的下家开始**逐张轮流发，直到发完。人数除不尽时靠前的人多一张。
- 选项 3 是**响应**：别人打出洗牌并选了选项 1 时，你可以打出自己的洗牌取消它。取消者**不进入自己的回合**，从**取消者的下家**继续出牌——与劫营 01-G5 同构。

#### 2026-07-31 规则制定人裁定（四条，实现所依据）

| # | 问题 | 裁定 |
|---|---|---|
| 洗-1 | 选项②「摸一弃一」弃哪张、何时定 | **先摸后弃**：摸 1 张之后开一个**只给打出者自己**的窗口，从**全部手牌（含刚摸那张）**里挑一张弃进**弃牌堆**；超时默认弃刚摸的那张 |
| 洗-2 | 选项①重分后有人分到 0 张 | **不判胜**，见 01-U5b；若那人是打出者，交回合时补摸 1 张并须喊 UNO（他人可抓） |
| 洗-3 | 选项③取消的结算形状 | **完全照抄劫营 01-G5**：取消牌压**牌顶**、跟色 = **取消者自己定的色**；窗口开给**所有手上有洗牌牌的其他玩家**、**先到先得**；取消者**不进入自己的回合**，从**取消者的下家**继续 |
| 洗-4 | 取消能否被再取消（连锁） | **不能**。只有**选择了选项①**的洗牌才开取消窗口；取消（选项③）本身不是选项①，落地即定 |

补充推论（由上表与既有规则直接得出，非新裁定）：

- 三个选项**都要定色**（卡面「三选一并决定颜色」），所以选项③的取消牌同样带 `chosenColor`，这正是洗-3 里「跟色 = 取消者定的色」的来源。
- 被取消者的回合就此结束；他若把洗牌当末牌打出而洗牌被取消 → 交回合时手牌为 0 → 按 01-U5 补摸 1 张。
- 取消者用掉的是自己的一张洗牌牌（功能牌）；若那是他最后一张手牌，按 01-U5 **不判胜**、补摸 1 张。
- 选项②、③**不开**取消窗口（洗-4）；毒与洗牌都是无色牌，而劫营♦10 要求同色同数 → 这两张牌天然不在劫营的触发面内。
