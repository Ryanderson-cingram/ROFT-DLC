# 术语与状态（来自 Excel Q&A + 裁定）

## 1. 基础用语

| 术语 | 定义 |
|---|---|
| 惩罚 | **仅**因 +2 与 +4 的摸牌。打出毒等不是惩罚。被惩罚的回合不能使用主动技能（有例外）。 |
| 明/扣置 | 移除游戏并保留在玩家面前。 |
| 展示 | 将手牌给其他玩家看一眼。 |
| 明示 | 将这部分手牌正面向上放在桌面上。 |
| 亮出手牌 | 将所有手牌正面向上（算作明示）。明示的手牌被洗牌后不再明示。 |
| 牌面 | 1–9、0、+2、停、转、变色、+4、洗牌、毒。颜色：红蓝黄绿 + 彩色。 |
| 功能牌 | +2、转、停 |
| 变色牌 | 变色、+4、毒、洗牌 |
| 出牌堆 | 正常打出的牌 |
| 弃牌堆 | 被弃置的牌 |
| 牌河 | 出牌堆 + 弃牌堆 |
| 单体技能 | 只能指定一名玩家的技能 |
| 技能免疫 | 其他玩家所有技能对你无效（含全局）；你也不能触发其他玩家的技能 |

## 2. 摸弃约束

所有摸牌与弃牌中，**摸到手里的牌数量不能少于弃牌数量**。

## 3. 拼点

两名玩家分别从牌堆翻出一张牌比大小；**相同视为发起人胜利**。

优先级：

`+4` > `洗牌` > `变色` > `转` > `+2` > `停` > `数字牌` > `毒`

数字牌之间：**比点数**（9 > 8 > … > 0）；点数相同 → 发起人胜。

## 4. 状态（负面三者互斥，不叠层）

当玩家有「五彩」「心盲」或「恋战」时，**不能获得另外两种**。所有状态不能叠加多层。

| 状态 | 效果 |
|---|---|
| 五彩 | 不能打出只是颜色相同的牌；使用变色牌时不能改变颜色 |
| 恋战 | 因无牌打出而摸牌时，需摸到能打出为止（最多五次） |
| 心盲 | 不能打出只是数字相同的数字牌；功能牌和变色牌不影响 |
| 领域 | 扣置摸到的所有牌；免疫恋战。（摸N弃N 与洗牌获得的牌不是「摸到的牌」） |
| 同命 | 一名同命玩家**受惩罚**（仅+2/+4）时，另一名摸相同数量，然后移除全部同命。打出毒不触发 |
| 狂欢 | **buff**（非技能）：灾难触发后，对方掷 2 + 灾难方掷 4 共六骰**加总**，**只有灾难持有方**按该总和获得表内效果，对方无效果；不替换对方技能；灾难方技能移除；总和 ≥5 → 时神技能 |

## 5. 标记（不完全列表）

| 标记 | 主要来源 | 用途摘要 |
|---|---|---|
| 魂 | 影歌 | 2 魂跳过本回合（可在惩罚回合） |
| 盗 | 司夜 | 换手牌；3/5 盗改胜利条件 |
| 异 | 异议 | 受惩罚时弃异少摸 |
| 形 | 万变 | 10 形换未上场技能 |
| 颠 | 邪神 | 可当作异/盗/魂/形 |
| 陨 | 诸神黄昏挑战 | 达玩家人数一半（向上取整）失神 |
| 神化 | 多种 | **标记，不是状态**（2026-07-29 裁定）：持有 N 枚 → 本回合可连出 **N+1 张**牌，且**只有最后一张能是功能牌**（G1–G3）；主神在场时全局 ≤3（G4） |

## 6. 洗牌（牌）

合并并打乱所有玩家手牌，从下家开始每名玩家依次获得一张牌。

## 7. Q&A 个别裁定（摘录）

| 技能 | 裁定 |
|---|---|
| 精英♥3 | 发动时最大为 9，下家按牌面数字继续 |
| 劫营♦10 | 可响应并列任意一张；神化额外出牌也可打断 |
| 血棘♦2 | 合纵/连横被血棘时两人同时失去；未亮出也被血棘则不能亮出 |
| 伤逝♥10 | 点数为 0 = 惩罚摸 0，但仍可受其他技能效果 |
| 专精♥9 | 抽到变色牌可自选颜色 |
| 回溯♥J | 牌不在打出/弃牌区则不能发动；结算 +4 时惩罚完成后再一张张结算；若你是被惩罚者不能发动 |
| 染手♠K | 摸牌堆空需要洗牌时，牌河里所有牌都会被洗 |
| 万变♣8 | ✅ ♣8；掷骰占主动；形达10强制换技能并归零；排除宏伟/灾难/宝藏/狂欢/预兆/飞升及四神 |
| 迫近♥2 | 接管 = 使用其手牌并帮其选择出牌或摸牌结束本回合 |
| 伪神♣6 | 视为神明（详见 01 G7–G9） |
| ⌘主神 | ✅ 统一用 ⌘；神官不可向主神发起挑战 |
