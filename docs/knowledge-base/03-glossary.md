# 术语与状态（来自 Excel Q&A + 裁定）

## 1. 基础用语

| 术语 | 定义 |
|---|---|
| 惩罚 | **仅**因 +2 与 +4 的摸牌。打出毒等不是惩罚。被惩罚的回合不能使用主动技能（有例外）。 |
| 明/扣置 | 移除游戏并保留在玩家面前。 |
| 展示 | 将手牌给其他玩家看一眼。 |
| 明示 | 将这部分手牌正面向上放在桌面上。 |
| 亮出手牌 | 将所有手牌正面向上（算作明示）。明示的手牌被洗牌后不再明示。 |
| 牌面 | 1–9、0、+2、停、转、变色、+4、洗牌、毒。颜色：红蓝黄绿 + 彩色。 |
| 功能牌 | +2、转、停 |
| 变色牌 | 变色、+4、毒、洗牌 |
| 出牌堆 | 正常打出的牌 |
| 弃牌堆 | 被弃置的牌 |
| 牌河 | 出牌堆 + 弃牌堆 |
| 单体技能 | 只能指定一名玩家的技能 |
| 技能免疫 | 其他玩家所有技能对你无效（含全局）；你也不能触发其他玩家的技能 |

## 2. 摸弃约束

所有摸牌与弃牌中，**摸到手里的牌数量不能少于弃牌数量**。

**「摸 N 弃 N」是一个窗口**（规则制定人 2026-08-02）：一次摸满 N 张、再从手牌里挑 N 张弃掉，
**不是 N 个「摸 1 弃 1」**。原话：「一个窗口摸 N 弃 N」。因此：

- 弃的 N 张从**摸完之后的整副手牌**里挑，可以包含刚摸到的、也可以是原本就有的
- 中途没有可观察的中间态，别人插不进来——同并列整组落地（04 ♥4 2026-08-02）的口径
- 用到它的：合纵♠5（摸 2 弃 2）、连横♠6（摸 1 弃 1 / 摸 3 弃 3）、八门♠8（摸 8 弃 8）、
  心火♠Q、黑白♣9、染手♠K、古神 ≥6。洗牌牌选项②的「摸一弃一」是 **N = 1 的特例**，
  引擎里那个 `drawDiscard` 窗口是它们共用的实现（2026-08-02 由洗牌②的窗口泛化而来）
- 层级只结算一次：摸那 N 张走的是 02 §7 的 L0–L6（活泼板那类修正对它照样生效），
  **弃的张数照牌面走、不吃层级修正**——L0–L6 改的是摸，没有哪一层改弃

## 3. 拼点

两名玩家分别从牌堆翻出一张牌比大小；**相同视为发起人胜利**。

优先级：

`+4` > `洗牌` > `变色` > `转` > `+2` > `停` > `数字牌` > `毒`

数字牌之间：**比点数**（9 > 8 > … > 0）；点数相同 → 发起人胜。

## 4. 状态（负面三者互斥，不叠层）

当玩家有「五彩」「心盲」或「恋战」时，**不能获得另外两种**。所有状态不能叠加多层。

| 状态 | 效果 |
|---|---|
| 五彩 | 不能打出只是颜色相同的牌；使用变色牌时不能改变颜色 |
| 恋战 | 因无牌打出而摸牌时，需摸到能打出为止（最多五次） |
| 心盲 | 不能打出只是数字相同的数字牌；功能牌和变色牌不影响 |
| 领域 | 扣置摸到的所有牌；免疫恋战。（摸N弃N 与洗牌获得的牌不是「摸到的牌」） |
| 同命 | 一名同命玩家**受惩罚**（仅+2/+4）时，另一名摸相同数量，然后移除全部同命。打出毒不触发 |
| 狂欢 | **buff**（非技能）：灾难触发后，对方掷 2、灾难方掷 4，**双方各按自己骰子的总和**查表获得效果（各算各的，不相加）；不替换对方技能；灾难方技能移除；灾难方总和 ≥5 → 时神技能 |

## 6. 洗牌（牌）

合并并打乱所有玩家手牌，从下家开始每名玩家依次获得一张牌。

⚠️ 这是**卡面三选一里的选项①**，不是「摸牌堆见底时把牌河洗回摸牌堆」（那条见 01-U8）。
完整卡面（三选一 + 定色）与四条裁定见 **05 §2b**。
