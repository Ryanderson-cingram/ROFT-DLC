## 3. 回合阶段（标准回合）

顺序固定：

1. **回合开始** — 可亮出技能；可发动主动技能（非惩罚回合）  
2. **出牌或摸牌** — 打出合法牌；或无牌可出则摸牌（摸到可打可立即打出）  
3. **出牌结算** — 功能/变色/惩罚/毒/洗牌等；**牌面触发的被动在此结算**  
4. **回合结束** — 下家（被「停」则跳过其开始窗口）

| ID | 规则 | 状态 |
|---|---|---|
| T1 | 主动技能默认只在阶段 1 | ✅ |
| T2 | 例：司夜打出变色后获得「盗」在阶段 3；花「盗」要等到下次阶段 1 | ✅ |
| T3 | 技能在回合开始时可使用；被 +2/+4 的惩罚回合默认不能主动用技能 | ✅（用户补充 + Q&A） |

## 7. UNO 基础（用户补充 + Excel）

| ID | 规则 | 状态 |
|---|---|---|
| U1 | 无牌可出（或选择不打）→ 摸牌；摸到符合规则可立即打出 | ✅ |
| U2 | 打出多张牌结束游戏时无需喊 UNO（Q&A） | ✅ |
| U3 | 其余牌面交互以 Excel「牌」表 + 传统 UNO 为底，叠罚规则见 §5 | ✅ |
| U4 | 拼点：总序见 glossary；数字牌比点数；**相同则发起人胜** | ✅ |
| U5 | **功能牌不能作为最后一张牌结束游戏**：+2 / 停 / 转 / 变色 / +4 / 毒 / 洗牌打出后，**这张牌自身的效果全部结算完、准备交回合的那一刻**手牌若仍为零，**须再摸 1 张**，游戏继续；只有数字牌能打完获胜 | ✅ |
| U6 | **喊 UNO**（原 Q26；2026-08-01 改判，2026-08-02 再改判）：喊的按钮**常亮**，任何时刻都按得下去，按下**只记录「这回合喊过」，当场不判、不罚**。**唯一的结算在交回合那一刻**：手牌恰为 1 → 声明成立并跟着那张牌存续；**不是 1 张 → 声明作废，且罚摸 2 张**（规则摸牌非惩罚，同 U7 的抓）。喊与出牌是**两个互不影响的动作**，喊不占出牌机会。**已喊在你自己的回合内一直有效**，回合中手牌数怎么波动都不必重喊。**回合之外**手牌一离开 1 张，已喊立刻作废 | ✅ |
| U7 | **抓漏喊**（原 Q26）：持 1 张且未喊者，**任何**玩家不限回合可抓（含反应窗口期间）；窗口自其**回合结束后 1 秒**开启（2026-08-02 追加，见下方补充）——**本人回合内是宽限期，抓不得**；至其补喊或手牌离开 1 张为止；被抓**摸 2 张**——属规则摸牌**非惩罚**（P1），同命/恩惠等「受惩罚时」效果不响应；补喊与抓先到先得（乐观锁串行化） | ✅ |
| U8 | **洗牌与平局**（规则制定人 2026-07-31）：摸牌堆摸空时，把**出牌堆**（除牌顶那张）与**弃牌堆**一并洗回作为新的摸牌堆，牌顶与全体手牌**原样保留**，从出牌堆继续；**整局最多洗 2 次**。洗满 2 次之后摸牌堆再度见底而仍无人获胜 → 本局**平局**（终局，无赢家） | ✅ |

**U5 补充**：

- 该牌**照常结算**——最后一张打的是 +2/+4 时惩罚链仍然成立并传给下家，转仍翻向，停仍跳过下家；只是打出者没赢，且摸完 1 张后手上至少有 1 张牌
- **判定时点是「结算完毕、准备交回合」而不是「牌一离手」**（规则制定人 2026-07-31，为毒/洗牌落地而澄清）。原话：「打完功能牌就结束回合或者到下一人回合了，手里不多获得牌的情况下需要摸 1；打完毒之后会摸三张，结束回合时手里仍然有牌所以不需要额外摸」。因此：
  - **毒**作末牌 → 自身效果摸 3 张，交回合时手牌 3 张 ≠ 0 → **不补摸**，共 3 张
  - **洗牌·选项①（洗牌）**作末牌 → 参与合并重分；分到牌则不补摸，分到 0 张（下方 §7-U5b）才补摸 1
  - **洗牌·选项②（摸一弃一）**作末牌 → 摸 1 弃 1 后手牌又归零 → **补摸 1**，共 1 张
  - +2 / +4 / 停 / 转 / 变色 自身不给打出者加牌，判定时点前后同解，**行为不变**
- **U5b 洗牌重分得 0 张**（规则制定人 2026-07-31）：选项①重分后某人手牌为 0（全场手牌总数少于人数）→ **不判胜**（U2 的胜利条件是「打完最后一张」，靠洗牌分到 0 张不是打完）；若他正是打出洗牌的那个人，按上一条在交回合时**补摸 1 张**，随后手牌为 1 → **须喊 UNO**，他人可抓（U6/U7 照常）
- **U5c 收官判在末牌离手那一刻**（规则制定人 2026-08-01，原 06-Q59/Q61）：原话「如果盗标记够五个，可以打功能牌，**打出后无论选择什么都算胜利并结束**」。所以**收官判定**（U2 数字牌 / S16 司夜③ 的放宽）排在**这张牌自身的效果之前**：
  - 持够盗的司夜打出**毒**当末牌 → **当场获胜**，那 3 张不再摸；打出**洗牌**当末牌 → **当场获胜**，三选一不再结算、取消窗口不会开，别人夺不走
  - 门槛见 04 club-3③：**3 盗** = 末牌可为功能牌（+2/停/转），**5 盗** = 末牌可为变色牌（变色/+4/毒/洗牌）
  - ⚠️ **与 U5 的补摸是两个不同的判定时点，别合并**：**收官**判在牌离手时，**补摸 1 张**判在效果结算完、准备交回合时。收不了官的人才会走到补摸那一步
  - 由此 U5b 的适用面收窄为「**收不了官的人**分到 0 张」——他补摸 1 张、须喊 UNO，游戏继续
- S16「司夜放宽末牌可为功能/变色」正是对本条的例外，反过来印证了默认限制
- 摸的这 1 张是 U5 的代价，**不是惩罚**（P1：惩罚仅指 +2/+4 造成的摸牌），因此不触发同命等「受惩罚时」的技能
- 胜利只判定在**出牌**：技能弃牌（如恒心弃掉最后一张）使手牌瞬间归零**不判胜**，技能后续摸牌照常执行（06-Q54）
- 付不起代价的主动技能**不能发动**，发动机会不消耗；通则，适用所有带代价的技能（06-Q54）

**U6/U7 补充**（规则制定人 2026-08-01 改判，取代原「手牌数一离开 1 张就作废」的全局口径）：

- 原话（2026-08-01，分两次给出）：「喊出 UNO 按钮可以在还有 2 张时出现（或亮起（平时暗着））。一回合内多次手牌变为 1 的情况，在回合结束前喊就好，不用每次都喊。回合结束后，其他玩家可以抓没喊 uno」——追加澄清：「**如果先喊，喊的时候还有两张手牌也需要罚**，即喊 UNO 动作不影响出牌动作，可以出手牌后点击喊 UNO，并且如果回合结束手里剩一张牌忘了喊 UNO，在其他人回合没有被抓的时候也可以点击喊」
- **按钮常亮，按下只记录**：不做资格拦截（不 reject），按下即受理，**当场不判手牌数、不罚**。手牌数在按下那一刻是多少都无所谓——它只把「这回合我喊过」记下来
- **声明的作用域是「你的这个回合」**：一回合内手牌反复穿过 1 张（恒心弃 1 摸 1、远星弃 1 摸 2、洗牌②摸 1 弃 1），**回合内喊过一次就够**，不必每次重喊
- **唯一的结算在交回合那一刻**（2026-08-02 改判，取代原「按下那一刻判 + 交回合只作废不追罚」）：
  手牌恰为 1 → 声明成立并存续；**不是 1 张 → 作废 + 罚摸 2 张**。
  原话：「按结束回合时算本回合喊的 UNO 是否正确……如果本回合先喊，那么即使回合一开始时正确的并喊了 UNO，
  但回合结束时不正确也算不正确」。
  - 例：手上只有一张**毒**，喊 UNO（此刻恰 1 张）→ 打出毒当末牌 → 自身效果摸 3 张 →
    交回合时 3 张 → **罚摸 2**，共 5 张。喊的那一刻没错，但**结算看的是回合末**，这是有意的
  - 例：手上 2 张先喊 → 打掉 1 张 → 交回合时恰 1 张 → **成立，不罚**。「预喊」本身不再有即时代价，
    代价在回合末统一算
  - 回合外的补喊没有「你的回合末」可等：它由 `syncUno`「回合外手牌一离开 1 张即作废」当场兜住，
    所以拿着 3 张在别人回合点一下等于白点（声明当场作废），既不成立也不罚
- **回合之外**沿用旧口径：手牌一离开 1 张，已喊立刻作废。所以别人的技能（司夜②换牌、影歌②交牌…）把你从 1 张顶开又推回 1 张，你仍须重喊
- **忘喊可补**：回合结束时剩 1 张却忘了喊，在别人回合里仍可随时点（此时手牌恰 1 张，不算虚喊、不罚），只要还没被抓；补喊与抓**先到先得**
- **宽限期 = 你自己的回合**：U7 的抓窗口「自其回合结束开启」是硬门闩——你在自己回合内持 1 张未喊也**抓不得**，回合一交出去立刻可抓
- **代价**：在**别人**回合里被打到 1 张（劫营♦10 打断出牌）没有宽限期，当场可抓——「抢在别人之前点喊」这一下是真的要抢。2026-08-02 之后先喊不再有即时罚，所以抢喊的代价降到了零，这一条不再是痛点
- 抓的仍是**当下**：`catchUno` 只看目标此刻是否「持 1 张 + 未喊 + 不在自己回合」，不追溯历史上曾经漏喊的回合

**U7b 交回合后的 1 秒宽限**（规则制定人 2026-08-02）：抓窗口不是在回合一交出去就开，而是**再等 1 秒**。
原话：「玩家只剩一张牌时并结束回合后有一秒时间窗口点击 UNO（防止其他玩家恶意秒抓）」。

- **为什么需要**：U6 的「忘喊可补」写着补喊与抓**先到先得**，可这条起跑线对被抓者极不公平——
  他要先看到自己回合结束、再把手移到 UNO 键上；抓的人早就把光标压在按钮上等着，甚至可以脚本秒点。
  没有这 1 秒，「补喊」这条规则在实战里基本兑现不了
- **门闩落在谁身上**：宽限**只保护刚交出回合的那个座位**。在别人回合里被顶到 1 张的（劫营♦10 打断、
  司夜②换牌、影歌②交牌）**没有**这 1 秒——那些场景本来就没有回合结束这个时点，U6 补充里
  「劫营那一下是真的要抢」的口径不变
- **判定归引擎**：`catchUno` 在宽限内一律 `uno_grace` 拒收。UI 侧只是**不显示**按钮
  （宽限截止时刻随快照下发，客户端到点自己重画），与倒计时环同一套做法——客户端零规则照旧
- **1 秒是下限不是上限**：人的反应时间约 250ms，1 秒够挡掉脚本秒抓与「手一直压在按钮上」，
  但对真正走神的人帮助有限。若日后觉得还是抢不过，调大这一个常量即可（`UNO_GRACE_MS`）

**U8 补充**：

- 三堆的划分见 06-Q55：**出牌堆**（正常打出的牌，牌顶是跟牌目标）/ **弃牌堆**（被技能等弃掉的牌）/ **摸牌堆**。洗回时前两堆同时清空回摸牌堆，只有牌顶那张留在出牌堆上
- 平局的判定条件只看**牌堆状态**（洗满 2 次 + 摸牌堆见底 + 无人获胜），不是「没人能动了」——所以它是确定的，跟谁手上还有什么牌无关
- 判定时点是**回合交接**：这一轮的全部结算跑完、反应窗口都结掉、轮到下一个人时才收场，不在半路终止一条惩罚链
- 洗满之后仍可继续出牌，但**摸不到牌**（该摸 N 张实际摸到 0 张，见 06-Q46）；这个局面一到回合交接就是平局，所以实际上撑不过一次交接
- **未定**：平局之后是否比手牌数分高下、是否有别的收场方式，规则制定人尚未裁定 → 见 06-Q58
