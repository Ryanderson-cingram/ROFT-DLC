## 3. 回合阶段（标准回合）

顺序固定：

1. **回合开始** — 可亮出技能；可发动主动技能（非惩罚回合）  
2. **出牌或摸牌** — 打出合法牌；或无牌可出则摸牌（摸到可打可立即打出）  
3. **出牌结算** — 功能/变色/惩罚/毒/洗牌等；**牌面触发的被动在此结算**  
4. **回合结束** — 下家（被「停」则跳过其开始窗口）

| ID | 规则 | 状态 |
|---|---|---|
| T1 | 主动技能默认只在阶段 1 | ✅ |
| T2 | 例：司夜打出变色后获得「盗」在阶段 3；花「盗」要等到下次阶段 1 | ✅ |
| T3 | 技能在回合开始时可使用；被 +2/+4 的惩罚回合默认不能主动用技能 | ✅（用户补充 + Q&A） |

| ID | 规则 | 状态 |
|---|---|---|
| U1 | 无牌可出（或选择不打）→ 摸牌；摸到符合规则可立即打出 | ✅ |
| U2 | 打出多张牌结束游戏时无需喊 UNO（Q&A） | ✅ |

| U4 | 拼点：总序见 glossary；数字牌比点数；**相同则发起人胜** | ✅ |
| U5 | **功能牌不能作为最后一张牌结束游戏**：+2 / 停 / 转 / 变色 / +4 / 毒 / 洗牌打出后手牌若归零，**须再摸 1 张**，游戏继续；只有数字牌能打完获胜 | ✅ |

**U5 补充**：

- 该牌**照常结算**——最后一张打的是 +2/+4 时惩罚链仍然成立并传给下家，转仍翻向，停仍跳过下家；只是打出者没赢，且摸完 1 张后手上至少有 1 张牌
- S16「司夜放宽末牌可为功能/变色」正是对本条的例外，反过来印证了默认限制
- 摸的这 1 张是 U5 的代价，**不是惩罚**（P1：惩罚仅指 +2/+4 造成的摸牌），因此不触发同命等「受惩罚时」的技能
