# 司夜 ♣3（club-3）——变色获盗 / 花盗换牌 / 盗改末牌

先读 `README.md`；用基建 2a（rollDice，含强袭②接管流程）。规则出处：01-T2、01-S16、04 club-3 条目（含 2026-07-30 补齐的②汇率流程）、06-Q11（放宽仍须合法打出）、06-Q57（②③被动、不占、同回合皆可）、06-Q34（①获盗不占、惩罚轮打 +4 照样获盗）。

## 一句话

①：打出变色牌（wild / +4）后掷 1 骰获等量「盗」。②：1 盗 = 从一名玩家手里盲抽 1 张，再还 1 张。③：3 盗自动放宽末牌可为功能牌、5 盗可为变色牌，出末牌时自动扣盗。

## ① 获盗——精确行为

- 触发：**自己打出任意无色牌**（`color === null`：wild / +4；诸神包的毒、洗牌本批不管）后，阶段 3（after_play）自动掷 1 骰（0/1/2），`gainMarks(seat, "盗", 点数)`——无上限参数（盗没有标注上限）。
- **不是可选发动**：打出即掷（06-Q34「不是可选的发动」），不占 V7；**惩罚轮打出 +4 照样触发**。
- 掷骰走强袭②的两段式（README 3 号 spec）：无强袭在场时快速路径直掷。
- 时序：获盗在**该次出牌的结算内**完成（+4 开惩罚窗口之前把骰掷完、盗加上——窗口只能有一个，diceTakeover 与 punishStack 不能同时挂；顺序：先掷骰/接管窗口 → 结算盗 → 再开 punishStack 窗口。实现用 pendingDice.resume 里带「接着开惩罚窗口」的后续）。
- 事件：`diceRolled { reason: "nightlord-steal" }` + `marksGained { public: { seat, mark: "盗", n, total } }`（标记公开，03 §5）。

## ② 花盗换牌——精确行为

- 时机：**自己的阶段 1**（turnStart、无窗口挂起）。不是「发动」（06-Q57）：不占 V7、不做发动声明，但换不换、和谁换、还哪张是玩家的选择——引擎上仍是一个动作。
- 新 Action：`{ type: "stealSwap", seat, target: number }`，每次消费 `spendMarks(seat, "盗", 1)`；盗不足 → reject `cost_unpayable`。同一阶段 1 可连发多次（每次 1 盗）。
- 流程（一次 stealSwap 内两步，第二步是玩家选择 → 需要窗口）：
  1. 从 `target` 手牌**盲抽** 1 张（`ctx.rng` 均匀取下标，抽走的牌离开对方手牌进自己手牌；随机结果入 audit：`{ index }`）。target 手牌为 0 → reject `bad_target`；target === seat → reject `bad_target`。
  2. 开 `pendingWindow { type: "swapReturn", actors: [seat], deadline: 30s, defaultChoice: "first" }`——司夜者从**自己现在的手牌（含刚抽那张）**选 1 张还给 target：`respond(windowId, choice: cardId)`。超时默认还**刚抽到的那张**（最不泄露、最保守）。
- 隐私：抽到什么、还了什么 → `private` 只发给双方（seat 与 target 各一份 private 事件——**注意** EngineEvent.private 只支持单座位，发**两条**事件各带一方的 private）；public 只有 `{ seat, target }`「谁与谁换了 1 张」。手牌计数变化自然公开。
- 与 V7/T1 的关系：不占额度，且**不挡**同回合再发动主动技能（司夜没有 active 效果，此条自然成立）；③同回合仍可用（06-Q57）。

## ③ 盗改末牌——精确行为

- 常驻被动（06-Q57 自动触发）：出**最后一张手牌**时——
  - 持 ≥3 盗且末牌为**功能牌**（+2/停/转）→ 合法收官获胜，自动 `spendMarks 3`；
  - 持 ≥5 盗且末牌为**无色牌**（变色/+4）→ 合法收官获胜，自动 `spendMarks 5`。
- 「仍须合法打出」（06-Q11/S16）：那张牌本身要能接上（isPlayable / 惩罚轮则须是合法叠牌）。**不改 U5 的摸 1 逻辑以外的任何结算**：牌照常生效（+2 进链传给下家后游戏已结束？——收官获胜即 `finished`，链不再结算：01-U5 补充只在「没赢」时才谈照常结算；这里赢了，直接终局。在 spec 层面明确：**胜利优先，链/停/转不再结算**）。
- 盗不足 → 走原 U5：摸 1 张不判胜。恰好 3 ≤ 盗 < 5 而末牌是无色 → 同样走 U5。
- 扣盗自动发生，不需要玩家声明（Q57「持够盗时出末牌自动放宽并扣盗」）。若玩家**不想**在此刻花盗收官——不存在这个选项（自动），已裁定。
- UNO 规则照常（S16）：打到剩 1 张的前一轮照常 U6。

## 引擎接入

- `play-cards.ts`：①挂在无色牌结算路径；③挂在 `hands[seat].length === 0` 分支（在 U5 判定之前查盗）。
- ②新 action 进 types.ts / index.ts 分发 / `legalActions`（阶段 1、自己回合、盗 ≥1 时对每个有手牌的 target 各给一条）。`swapReturn` 窗口进 respond 分发。
- **快照补标记**：`SnapshotPlayer` 加 `marks: Record<string, number>`（03 §5 标记公开；影歌的魂同样受益）。projectView 带上，写「公开可见」测试。
- 机制注册：`dice` 已由强袭注册（若你先做，注册之）；`play_legality` 已由并列注册。
- web：阶段 1 盗 ≥1 时给「花 1 盗换牌」按钮（从 legalActions 的 stealSwap 动作生成，含 target 选择）；swapReturn 窗口弹手牌选择面板（复用恒心的选牌 overlay 模式）；HUD 玩家条显示标记徽记（`盗 ×N` / `魂 ×N`）。

## 测试清单（最低）

1. ①打 wild 掷 2 → 盗 +2；打数字牌不掷；惩罚轮叠 +4 → 照样获盗。
2. ①与 punishStack 的时序：+4 打出 → 先骰后窗，两个窗口不同时挂。
3. ② happy path：盗 −1、抽走的牌在自己手、还的牌在对方手；「还刚抽那张」= 双方手牌恢复原状仅盗 −1。
4. ②隐私：public 搜不到牌 id；双方各收到 private。
5. ②边界：0 盗 / 抽自己 / 对方空手 → reject；超时默认还刚抽那张。
6. ③：3 盗打末张 +2（能接上）→ 获胜、盗归 0、链不结算；2 盗同局面 → U5 摸 1 不判胜；5 盗打末张 +4（惩罚轮合法叠）→ 获胜。
7. ③「仍须合法打出」：3 盗但末张功能牌接不上牌顶 → illegal_card。
8. 快照：各座位都能看到别人的盗/魂计数。
