## 2. 缺口清单（按「会不会影响真人测试」排序）

### 2.1 🔴 会被玩家当场撞到

> **补齐方案见 `2026-08-04-batch-2-ui-gaps.md`**：五条收敛成三个改动点，全部零引擎改动
> （A1+A5 = 手牌被外力改动的提示，A2+A3 = 共用的 `chosen` 徽，A4 = 一行文案）。

| # | 缺口 | 现状 | 建议 |
|---|---|---|---|
| A1 | **合纵/连横结盟后的换牌没有前端** | 引擎有 `activateSkill(1b)`，坞里会出现「发动技能」按钮；但**互换整副手牌**这件事在 UI 上只有一行日志，手牌会「凭空全变」 | 加一条明显的过场提示（Ticker 高亮 + 手牌抖动），否则玩家以为出 bug |
| A2 | **专精的「你的色」在 UI 上看不见** | 只有日志里那条 `skillRevealed`，牌桌上没有任何标识 | 座位卡上挂一个色点（`chosen["heart-9"]` 已经在快照里） |
| A3 | **吟游的当前歌声在 UI 上看不见** | 同上，`chosen["club-5"]` 在快照里但没画 | 牌桌中央或座位卡上常驻一行「♪ 战争序」 |
| A4 | **神授「先问一句」的窗口文案不解释为什么** | 只写「可以摸 N 张再弃 N 张」，玩家不知道这是神授给的选择权 | 文案补一句来源（`drawOffer` 的 `public` 里加 `reason`） |
| A5 | **近卫交牌的收牌方没有提示** | 只有一条日志「交了 2 张手牌给某某」 | 收牌方的手牌区要有进牌动效（复用抓漏喊那套 bump） |

## 4. 本文新增的两条裁定请求（B3 / A4 的落点）

- **B3**：专精③「变色牌只能选你的色」与行进曲「变色牌不能改变颜色」撞车时，
  引擎当前让**专精优先**（`legal.ts::requiredColor` 里专精排在前面）。
  另一种读法是「两条都要满足 → 撞车时这张变色牌打不出去」。
  **建议维持现状**：让一张牌变成不可打，玩家很难自己想明白
- ~~**A4**：`drawOfferOpened` 事件的 `public` 里加一个 `reason`~~ —— **撤回，不需要**：
  这个窗口的两个来源都是**受问者自己已亮出的技能**，`players[seat].skillId` 本来就在快照里，
  前端直接取名字即可（见 `2026-08-04-batch-2-ui-gaps.md` §4）
