# 毒（poison，5 张）——打出时摸 3 并定色

先读 `README.md`。规则出处：**KB 05 §2b「毒（5 张）」**、01-P1（打出毒不是惩罚）、01-P1b（同命不响应毒）、01-U5 + U5b（末牌判定时点，2026-07-31 澄清）、03 glossary（毒是变色牌/无色牌）。

## 一句话

无色功能牌。打出时**打出者自己**摸 3 张牌并指定颜色；这 3 张不是惩罚，摸完手牌非空，所以打完不获胜也不补摸。

## 精确行为

- **牌面**：`face: "poison"`，`color: null`。已在 `deck.ts::buildDeck` 的 `gods` 分支里发出（5 张），**牌组不用动**。
- **合法性**：无色牌，`isPlayable` 已经放行（`isWild` → 任何时候可打）。**不用改 `legal.ts`。**
- **定色**：与变色牌同一套机制——提交时带 `chosenColor`，不带则 `color_required`，有色牌带则 `color_not_allowed`。这两条 `playCards` 已经统一处理，**不用加分支**。
- **效果**：`drawCards(board, { kind: "rule", base: 3, seat: 打出者 }, ctx.rng)` 后 `giveTo`。
  - `kind: "rule"` 而不是 `"punish"`（01-P1：打出毒**不是**惩罚）也不是 `"skill"`（它是牌面效果，没有技能持有者）。三选一里只剩 `rule`。
  - 因此同命不响应（P1b）、恩惠不减（它只吃 `punish` 与**他人**技能，见 `draw-passives.ts::applies`）。这是 `kind` 选对之后的**自动结果**，不要写专门代码。
  - 张数 3 是**牌面常数**，不是技能数值——04 的 yaml 与 `paramsOf` 那一套管的是技能，毒不进那里。就近写成模块级常量并注明出处（05 §3 牌面）。
- **摸不到那么多**：牌堆见底 + 洗回上限（01-U8）已经由 `drawCards` 统一处理，摸到几张算几张。**不要**在这里加补救逻辑。
- **不设 `drawnPlayable`**：01-U1 的「摸到可打即可打出」只针对「无牌可出而摸的那一张」。毒摸的 3 张是出牌结算的一部分（05 §2b）。`resolvePlay` 已经把 `drawnPlayable` 置 null，别再动它。
- **U5**：摸完 3 张后手牌必然 ≥ 3（除非牌堆真的空到摸不出来）→ 不补摸。这是 README §1 的判定时点挪位带来的**自动结果**，不要给毒写 U5 的特例分支。
- **收官（01-U5c，2026-08-01 裁定）**：**判在牌离手那一刻，排在摸 3 张之前**。所以持 5 盗的司夜拿毒当末牌 → **当场获胜，那 3 张不再摸**。普通玩家收不了官，才会往下走摸 3 张。
  - 边界：牌堆彻底枯竭，摸到 0 张 → 手牌仍为 0 → U5 照常补摸 1（也可能摸不到）→ 不判胜。这条路径靠 U5 的通用代码走通，别特判。
- **不判胜**：毒是功能牌，`isNumberCard(card)` 为 false，既有的 U5 分支已经保证它打完不赢。
- **交回合**：毒不是 +2/+4（`punishFace` 为 null）、不是停/转，所以走 `settlePlay` 末尾的通用 `passTurn(played, seat, 1)` → 下家。**不用加分支。**
- **劫营♦10**：毒是无色牌，劫营要求同色同数（只有数字牌成立）→ `raidActors` 自然返回空，不开窗口。**不用管。**
- **惩罚链挂着时不能打毒**：`playCards` 的 `canStack` 已经拒（毒不是 +2/+4）→ `must_stack`。**不用管。**

## 事件

复用既有的 `drawEvents(seat, drawn, reshuffledOrder)`：`cardsDrawn` 公开只说「谁摸了几张」，
牌面走 `private`；洗回牌堆的话 `deckReshuffled` 的牌序进 `audit`。
**不需要**新事件类型——`cardPlayed` 已经带了这张毒和 `chosenColor`，「他打了毒所以摸 3」从牌面就能读出来。

## Worked example

4 人 A→B→C→D，牌顶红 7，A 手里 3 张（含 1 张毒）。

1. A 打出毒，`chosenColor: "B"`。
2. A 手牌剩 2 张；毒摸 3 张 → A 手牌 5 张。
3. 跟色变蓝，牌顶是毒；`activeFace` 为 null（单张出牌一律如此）→ B 要跟蓝色或另一张无色牌，或牌面 `poison`。
4. 轮到 B。全程没有惩罚链、没有窗口、`version` 恰好 +1。

**末牌情形**：A 手里只剩那 1 张毒 → 打出后手牌 0 → 毒摸 3 → 手牌 3 → **不补摸、不判胜**，轮到 B。
**例外**：A 若持司夜且有 5 枚盗 → 扣盗**当场获胜**，那 3 张不摸（01-U5c）。

## 引擎接入

- `play-cards.ts::settlePlay`：在 U5 补摸**之前**加一段「牌面自身效果」。毒只占其中一行。
- 其余文件**都不用动**（`deck.ts` / `legal.ts` / `types.ts` / `index.ts` / web 的 `cards.ts` 已经有「毒」的牌面标签）。

## 测试清单（最低）

1. Worked example 全断言：A 手牌 2→5、跟色蓝、牌顶是毒、轮到 B、`version` +1。
2. 末牌打毒：手牌 0 → 摸 3 → 手牌 3、`winner` 缺席、`phase` 不是 `finished`、**没有第 4 张补摸牌**。
3. 不是惩罚：A 亮着恩惠♥1（−2 至少 1）→ 仍然摸满 3 张（走的是 `rule` 不是 `punish`/他人技能）。
4. 不设 `drawnPlayable`：摸到的 3 张里就算有能打的，`board.drawnPlayable` 也是 null，`legalActions` 里没有「只能打那张」的收窄。
5. 定色：不带 `chosenColor` → `color_required`；带了但牌是有色牌的既有断言不回归。
6. 牌堆枯竭：`drawPile` 空 + 洗回已满 2 次 → 摸到 0 张，手牌为 0 时 U5 补摸那一条照常走，引擎不抛。
7. 基础包里没有毒：`buildDeck("base")` 不含 `face: "poison"`（既有断言，回归即可）。
8. 惩罚链挂着时打毒 → `must_stack`。
9. **01-U5c**：司夜持 5 盗以毒收官 → `winner` 当场落定、手牌仍为 0（3 张没摸）、盗扣 5；盗只有 4 枚 → 收不了官，照常摸 3 张。
